# Portfolio Agent Kit

Turn any project repository into a polished, evidence-based **`PORTFOLIO.md` case study** —
generated by a [Claude Code](https://claude.com/claude-code) subagent from the repo's git
history, docs, and structure — plus an optional **zero-dependency builder** that renders it as
a branded PDF, and a **slide-deck skill** that presents the project in 8–14 image-first slides
(self-contained HTML + 16:9 PDF) in the project's brand.

Nothing in the kit is project-specific: per-project settings (brand colors, fonts, file names,
page size) live in one small JSON config file *in your project*, and figures live in your
project's asset folder. Copy the kit between repos without editing a single file in it.

## What's inside

```
.claude/agents/portfolio.md             the agent definition
.claude/agents/portfolio/               docs + the optional Markdown → PDF builder
.claude/commands/portfolio-update.md    /portfolio-update — bounded-token incremental updates
.claude/skills/portfolio-deck/          /portfolio-deck — image-first slide deck (HTML + PDF)
```

## Install into your project

Copy all four pieces, preserving the paths:

```bash
mkdir -p <your-repo>/.claude/agents <your-repo>/.claude/commands <your-repo>/.claude/skills
cp    .claude/agents/portfolio.md            <your-repo>/.claude/agents/
cp -r .claude/agents/portfolio               <your-repo>/.claude/agents/portfolio
cp    .claude/commands/portfolio-update.md   <your-repo>/.claude/commands/
cp -r .claude/skills/portfolio-deck          <your-repo>/.claude/skills/portfolio-deck
```

Then, in Claude Code inside your project, ask: *"Generate the portfolio for this project."*
For small follow-up changes, run `/portfolio-update <change list>` — it edits the document and
rebuilds the PDF under a strict token budget instead of re-running the full agent. To present
the project, run `/portfolio-deck`: it distils the portfolio into a short, image-first deck
built from the project's own screenshots.

The case study opens with a **TL;DR** — a short summary, a line of sourced KPIs and a small
milestone timeline — so a reader who stops there has still understood the whole project.

The agent renders the value timeline as **stacked Mermaid `timeline` blocks** (max 4 value bets
per block) so it stays readable as the project grows, instead of one ever-compressing diagram.

# Portfolio Agent Kit

Turn any project repository into a polished, evidence-based **`PORTFOLIO.md` case study** —
generated by a [Claude Code](https://claude.com/claude-code) subagent from the repo's git
history, docs, and structure — plus an optional **zero-dependency builder** that renders it as
a branded PDF.

Nothing in the kit is project-specific: per-project settings (brand colors, fonts, file names,
page size) live in one small JSON config file *in your project*, and figures live in your
project's asset folder. Copy the kit between repos without editing a single file in it.

## What's inside

```
.claude/agents/portfolio.md    the agent definition
.claude/agents/portfolio/      docs + the optional Markdown → PDF builder
```

## Install into your project

Copy both pieces, preserving the paths:

```bash
mkdir -p <your-repo>/.claude/agents
cp    .claude/agents/portfolio.md <your-repo>/.claude/agents/
cp -r .claude/agents/portfolio    <your-repo>/.claude/agents/portfolio
```

Then, in Claude Code inside your project, ask: *"Generate the portfolio for this project."*
